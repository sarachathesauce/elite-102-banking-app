# Python Banking System:
## This is a simple banking app made with Python and SQLite. It allows users to create accounts, deposit and withdraw money, check balances, and view all accounts.

## To setup: 
# 1. Open the project in GitHub Codespaces or any Python environment

# 2. Run the database setup: (type and enter "python database.py" in Terminal)

# 3. Run the main program: (type and enter "python main.py" in Terminal)

## Features: - Create new bank accounts - Deposit money into an account - Withdraw money with balance validation - Check account balance - List all existing accounts - Menu-driven interface
